# Results

Generated by `python3 -m experiments.report` from `results/trials.csv` and `results/offline_eval.*`. Do not edit by hand; rerun the pipeline instead.

## Setup

- 70 (profile, seed) combinations x 6 timeout modes (ml, ml_v2, ml_v2_rack, rto, rto_k2, rto_rack) = 420 transfers; 10 seeds per profile; file size 1,048,576 bytes.
- Successful transfers: 420/420; independently SHA-256-verified: 420/420.
- ML model: target `direct`, config `deep`, margin 1.0, trained on 140 runs.
- All runs on one machine over loopback through the user-space impairment proxy (see limitations).
